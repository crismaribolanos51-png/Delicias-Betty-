# Delicias-Betty-
Delicias Betty es una página web de comida costeña esmeraldeña, hecha como proyecto de la Unidad Educativa Bolívar. Tiene inicio, datos informativos, carta con precios (platos a $5, corviches desde $1,25), la historia de Betty y su abuela Rosa, y ubicación y contacto. Incluye diseño adaptable, modo oscuro y sonido de olas del mar.
